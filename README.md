# SocialLift (by Srinkhala)

Marketing/landing site — TanStack Start (React 19) + Cloudflare.

## Stack
- TanStack Start + TanStack Router + TanStack Query
- Tailwind v4, Radix UI, shadcn-style components
- Vite, deployed to Cloudflare (`wrangler.jsonc`)
- Scaffolded via Lovable (`@lovable.dev/vite-tanstack-config`)

## Routes
`/` (index), `/about`, `/pricing`, `/contact`, `/results`

## Setup
```bash
npm install
npm run dev      # vite dev
npm run build
npm run preview
```
